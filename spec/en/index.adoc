= FPSOT version control specification
include::_fpsot-terms.adoc[]

This specification sets the rules for version control in {abbr-fpsot-first} projects.
It has two parts.

* xref:generic.adoc[Generic rules] apply to any version control system.
* xref:git.adoc[Git rules] apply to Git repositories and build on the generic rules.

== Conformance

[quote, RFC 8174]
____
The key words "MUST", "MUST NOT", "REQUIRED", "SHALL", "SHALL NOT", "SHOULD", "SHOULD NOT", "RECOMMENDED", "NOT RECOMMENDED", "MAY", and "OPTIONAL" in this document are to be interpreted as described in BCP 14 (RFC 2119, RFC 8174) when, and only when, they appear in all capitals, as shown here.
____

The keywords follow requirement WRT-010 of the {abbr-fpsot} writing specification.
The French version uses the French keywords of WRT-011.

A {term-repository} conforms to the generic part when it meets every MUST rule in that part.
A Git repository conforms to this specification when it meets every MUST rule in both parts.
