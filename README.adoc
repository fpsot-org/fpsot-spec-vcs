= FPSOT version control specification

Rules for version control in FPSOT projects: signed commits, commit messages, branches, merging and releases.
Version 0.2 is a draft.

== Implement this spec

Read the normative text in `spec/en/` or `spec/fr/`.
The generic part applies to any version control system.
The Git part applies to Git repositories.
Each requirement has an ID from `VCS-001` to `VCS-110`.

== Adopt this spec

Read the guide in `docs/modules/en/pages/index.adoc` or `docs/modules/fr/pages/index.adoc`.
To apply the rules to a GitHub repository, run `rules/apply-github.sh OWNER/REPO`.

== Layout

[cols="1,3"]
|===
| Folder | Content

| `spec/`
| Normative text, in English and French. `book.adoc` joins the pages into one book, published as PDF with each release.

| `docs/`
| Guides, in the Antora folder layout.

| `skill/`
| The agent skill: a short summary that cites requirement IDs.

| `rules/`
| The GitHub ruleset and the script that applies it.

| `diagrams/`
| The branch model, as PlantUML source and SVG.

| `jurisdictions/`
| Comparison data: how each government handles the same topics.
|===
